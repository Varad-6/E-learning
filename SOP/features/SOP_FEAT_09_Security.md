## 1. Authentication Architecture
Uses JSON Web Tokens (JWT) for session management:
*   Access Tokens (Short-lived, e.g., 15 minutes).
*   Refresh Tokens (Long-lived, e.g., 7 days) stored securely to regenerate access tokens automatically.
