## 1. Course Workflow States
```
 [Draft] ──► [Pending Approval] ──► [Approved] ──► [Published]
   ▲                 │
   └───────(Rejected)┘
```
1.  **Draft**: Work-in-progress, visible only to creator.
2.  **Pending Approval**: Submitted for review. Course is locked for edits.
3.  **Approved**: Checked and verified by Course Manager.
4.  **Published**: Live in course catalog and ready for enrollments.
