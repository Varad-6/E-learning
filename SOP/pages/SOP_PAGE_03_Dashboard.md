# 📊 Standard Operating Procedure: Dashboard Interface

**URL Route**: `/dashboard`  
**Version**: 1.0  
**Effective Date**: 09-Jul-2026  
**Audience**: All Users  

---

## 1. Interface Scopes by Role

### 1.1 Learner Dashboard (`EMPLOYEE`)
Displays current courses, module checklists, and quick metrics:
*   **My Courses**: Cards showing progress percentage.
*   **Deadlines Panel**: Days remaining for assigned modules.
*   **Completed Courses**: Badges and certificates list.

### 1.2 Department Manager Dashboard (`MANAGER`)
Tracks department learning progress:
*   **Department Scorecard**: Average quiz scores and compliance rates.
*   **Roster Summary**: List of direct reports and their current training statuses.
*   **Action Required**: Access override request escalations.

### 1.3 HR Admin Dashboard (`HR_ADMIN`)
Handles user rosters:
*   **User Grid**: Paginated list of users with filtering options.
*   **Onboarding Queue**: Newly created accounts.

### 1.4 Course Manager Dashboard (`COURSE_MANAGER`)
Manages course pipelines:
*   **Course Status Metrics**: Count of drafts, pending approvals, and published courses.
*   **Enrollment Stats**: Charts showing enrollment numbers.
