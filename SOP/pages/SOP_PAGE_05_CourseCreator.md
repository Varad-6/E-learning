# ✍️ Standard Operating Procedure: Course Creator Studio

**URL Route**: `/creator`  
**Version**: 1.0  
**Effective Date**: 09-Jul-2026  
**Audience**: Course Managers, System Admins  

---

## 1. Creating Content Modules
1. Click **Add New Module**.
2. Edit module properties: Title, Sequence, and Description.
3. Drag and drop modules to re-sequence. The frontend calls `/api/modules/reorder` upon release.
4. Click **Publish** to push modules live.
