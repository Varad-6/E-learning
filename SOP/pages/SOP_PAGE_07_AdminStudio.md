# ⚙️ Standard Operating Procedure: Admin Studio

**URL Route**: `/admin/studio`  
**Version**: 1.0  
**Effective Date**: 09-Jul-2026  
**Audience**: System Admins, HR Admins  

---

## 1. User Directory Grid
The User Directory lists all non-deleted employee records. Admins can search by email or name, and filter by department or active status.

---

## 2. Creating & Editing Users
*   **Add User**: HR Admins can create profiles. The backend handles default role assignment.
*   **Role Management**: Restricting SYSTEM_ADMIN role assignment to System Admins only.
